## 1. Резюме проекта

**Проблема:** Покупатель, который облицовывает крыльцо, лестницу или террасу, не находит в интернете специализированного поставщика именно клинкерных ступеней и крупноформатного керамогранита для улицы. Запросы «клинкерные ступени для крыльца», «ступени для лестницы на улице», «керамогранит для террасы 20 мм», «плитка для дорожек на опорах» ведут на общие плиточные каталоги без расчёта элементов, без понимания систем (проступь / подступёнок / угол / плинтус) и без цен.

**Решение:** Отдельный лендинг + подстраницы (категории, бренды и решения по применению). Ассортимент структурирован в **три продуктовые категории**:
1. **Террасный клинкер** — клинкерная плитка и ступени для крылец, уличных лестниц и террас (проступь/подступёнок/угол/капинос/базовая плитка), укладка на клей.
2. **Террасные пластины** — крупноформатный керамогранит 20 мм для террас, входных площадок и дорожек, в т.ч. укладка на регулируемые опоры (пьедесталы) и на клей.
3. **Террасные пластины под дерево** — крупноформатный керамогранит с текстурой дерева (декинг-эффект) для террас и зон отдыха.

Главная конвертирует рекламный трафик в заявки, подстраницы закрывают SEO/GEO-спрос по брендам, категориям и сценариям применения. Ключевой инструмент — **калькулятор с двумя режимами** (лестница/крыльцо и терраса/площадка), который считает не «квадраты вообще», а штуки плитки/ступеней по реальному размеру (30×30, 30×60), опоры по таблице производителя и сопутствующие материалы с ценой по городу.

**Цель:** Конверсия в заявку ≥ 3% с рекламного трафика; органический и AI-трафик (цитируемость в ChatGPT/Perplexity/Яндекс Нейро) через 4–6 месяцев после запуска.

**Ключевой дифференциатор:** Калькулятор лестниц с добавлением произвольного числа маршей и поэлементным расчётом ступеней в штуках + калькулятор террасы с выбором способа монтажа (клей / регулируемые опоры) и точным расходом опор по таблице HILST LIFT. Сопутствующие материалы (клей, грунтовка, гидроизоляция, затирка) с ценой по городу. Открытые цены, квиз подбора, 3D-визуализация, карта объектов — функционала такого уровня нет у конкурентов в нише уличного клинкера и террасного керамогранита.

## 2. Целевая аудитория

| Сегмент | Боль | Что хочет от сайта |
|---|---|---|
| Частный домовладелец (загородный дом, дача) | Не знает, чем облицевать крыльцо/лестницу/террасу, боится, что зимой треснет и будет скользко | Понять, что подойдёт для улицы (морозостойкость, R-противоскольжение), увидеть цену, рассчитать комплект, посмотреть как будет выглядеть |
| Ландшафтный дизайнер / архитектор | Нужны конкретные форматы, фактуры, толщина 20 мм, системы укладки на опоры для террас и дорожек | Каталог форматов и цветов, технические параметры, образцы, расчёт, прямая связь без посредников |
| Прораб / монтажная бригада | Нужно посчитать комплект ступеней (сколько проступей, углов, подступёнков) и не ошибиться | Поэлементный расчёт, наличие, цена за элемент, расход клея/опор, документы |
| Застройщик / благоустройство (B2B) | Входные группы, террасы, площадки на объёме — нужна цена и логистика | Оптовые цены, расчёт по площади, доставка, гарантии, сертификаты |

## 4. Трафик и SEO

### Яндекс.Директ
- Рекламные группы под два смысловых кластера: **ступени** (крыльцо, лестница) и **террасы/ландшафт** (керамогранит 20 мм, дорожки, опоры).
- Отдельные группы на страницы решений (выше конверсия, чем общий лендинг).
- UTM-метки (source, medium, campaign, content, term) сквозь передаются в Битрикс24.
- Конверсионные цели: отправка формы, клик по телефону, завершение квиза, отправка расчёта из калькулятора, заказ образца.

### SEO + GEO (цитируемость в AI)
- Уникальные Title, Description, H1 на каждой странице (шаблоны — в сопутствующем файле `seo_base`, создаётся отдельно после фиксации домена).
- Первый абзац подстраницы — самодостаточный ответ (что за продукт, для чего, ключевые параметры): лучше попадает в сниппеты и AI-ответы.

## 5. Дизайн (направление B — выбрано)

Заказчик выбрал **направление B** — «архитектурно-уличный», земляной, контрастный. Отстраивается от основного сайта the-one-temp.ru, ближе по настроению к ландшафту и террасам. (Альтернативное направление A в стиле Hit Ceramics рассматривалось для сравнения и отклонено.)

### Цветовая палитра

| Роль | Цвет | HEX |
|---|---|---|
| Фон основной | Холодный песочный / светло-серый | `#F2F1ED` |
| Фон тёмных секций | Графит | `#222624` |
| Основной текст | Почти чёрный | `#171717` |
| Вторичный текст | Тёплый серый | `#6B6560` |
| Акцент (CTA, ссылки) | Терракота / клинкер | `#B5532E` |
| Акцент hover | Тёмная терракота | `#8C3F22` |
| Дополнительный акцент | Тёплый зелёно-оливковый (ландшафт) | `#5B6B4F` |
| Разделители | Светло-серый песочный | `#DAD7CF` |

Типографика: заголовки **Manrope ExtraBold** (или **Unbounded** — современный, плотный), тело и интерфейс **Inter**, цены/числа **Inter SemiBold**. Характер «продуктовый», современный, не «классический».

### Общие правила дизайна
- **Фотостиль:** реальные объекты — крыльцо, лестница, терраса, дорожки. Крупные планы фактуры и капиноса ступени, ракурс «носик ступени». Кадры «до/после». Никакого стока.
- **Анимации:** fade+slide карточек при скролле; живые счётчики; hover-поднятие тени на карточках; параллакс на крупных фото; плавные переходы между страницами.
- **Логотип Hit Ceramics:** полноцвет на светлом фоне (шапка), белый — на тёмном (футер).
- **Адаптив:** сначала мобильный (основной трафик с Директа — мобильный).

## 6. Структура главного лендинга

Структура учитывает доработанную версию the-one-temp.ru (добавлены блоки «Преимущества», «Шоу-румы», «FAQ»).

### Блок 1 — Шапка (Header, sticky)
- Логотип (слева).
- Навигация: **Террасный клинкер / Террасные пластины / Под дерево / Решения / Калькулятор / Услуги / Блог**.
- Телефон (кликабельный tel:) + иконки WhatsApp, Telegram.
- Кнопка «Получить расчёт» (акцентная, CTA).
- При скролле фиксируется, фон белый с тенью.

### Блок 2 — Hero (первый экран)
- Фоновое видео/фото: крыльцо или терраса из клинкера в дневном свете (петля 5–8 сек, без звука, autoplay, loop; fallback — статичное фото).
- Полупрозрачный тёмный оверлей для читаемости.
- **H1** (6–12 слов): «Клинкерные ступени и крупноформат для крыльца, лестниц и террас».
- **Подзаголовок** (15–25 слов): УТП — морозостойко, не скользит, открытые цены, расчёт комплекта онлайн, доставка по РФ.
- **CTA:** «Подобрать решение» (→ квиз) и «Рассчитать комплект» (→ калькулятор).
- Полоса логотипов брендов (доверие, бесконечная прокрутка).

### Блок 3 — Три продуктовые категории (развилка)
Три крупные кликабельные карточки (на десктопе в ряд, на мобильном — стопкой):
- **Террасный клинкер** — плитка и ступени для крыльца, уличных лестниц и террас → `/terrasnyy-klinker/`
- **Террасные пластины** — крупноформат 20 мм для террас, дорожек, ландшафта (клей / опоры) → `/terrasnye-plastiny/`
- **Террасные пластины под дерево** — керамогранит с текстурой дерева (декинг-эффект) → `/plastiny-pod-derevo/`

### Блок 4 — Живые счётчики
```
[ 11+ лет на рынке ] [ N объектов ] [ N брендов ] [ 85 регионов доставки ]
```
Цифры анимируются при попадании в экран. Конкретные значения — из CMS / TBD у заказчика.

### Блок 5 — Преимущества (6 карточек)
Прямые контракты с заводами · импорт на складе в РФ · морозостойкость и противоскольжение (улица) · быстрый поэлементный расчёт · доставка по России и СНГ · гарантия качества и документы.

### Блок 6 — Решения по применению (карточки)
Крыльцо · Уличная лестница · Терраса · Садовые дорожки · Укладка на опоры · Зона бассейна. Каждая → своя страница решения. Под каждой — короткое пояснение и фото сценария.

### Блок 7 — Квиз «Подобрать решение»
(см. раздел 11.1) — 5 шагов, прогресс-бар. Результат: 2–3 рекомендованных артикула/комплекта + кнопки «Заказать образец» и «Рассчитать».

### Блок 8 — Калькулятор
(см. раздел 9) — два режима: «Лестница/крыльцо» и «Терраса/площадка». Реактивный результат, отправка менеджеру/в Telegram.

### Блок 9 — 3D-визуализатор крыльца/террасы
(см. раздел 11.2) — загрузка фото объекта / выбор сценария → наложение выбранного материала. Приоритет v2 (бюджет согласовать).

### Блок 10 — Каталог-витрина (популярное)
Сетка карточек: вперемешку топ-ступени и топ-форматы. Фильтр: Все / Террасный клинкер / Террасные пластины / Под дерево / для крыльца / для террасы. Карточка → карточка товара.

### Блок 11 — Виды и характеристики (образовательный блок)
Три-четыре карточки-объяснения, закрывающие страхи и SEO:
- **Клинкер для улицы** — высокотемпературный обжиг, морозостойкость F100+, водопоглощение < 6%, не скользит.
- **Керамогранит 20 мм** — толстый формат для улицы и опор, высокая нагрузка.
- **Противоскольжение (R-классы)** — что такое R10/R11/R12, где применять.
- **Системы укладки** — на клей по стяжке / на регулируемые опоры / на гравий.

### Блок 12 — Услуги
(см. раздел 10) — сетка карточек, у каждой своя форма и тег в CRM.

### Блок 13 — Карта объектов
Яндекс.Карты API. Маркеры реализованных крылец/террас. Попап: фото, город, бренд/артикул, год. Фильтр по типу (ступени/террасы). Управление маркерами из CMS.

### Блок 14 — Примеры работ (галерея)

## 9. Калькулятор

Калькулятор имеет **два режима** (табы). Переключение режима меняет поля ввода и формулы. Результат **реактивный** — пересчитывается мгновенно при любом изменении, без кнопки. Цены **редактируемые** (подставляются из CMS, пользователь может изменить).

```
[ Режим A: Лестница / крыльцо (ступени) ]   [ Режим B: Терраса / площадка (пластины) ]

Глобальный переключатель города:   ( • Москва )  ( ○ Санкт-Петербург )
```

### 9.0 Глобальный переключатель города (Москва / Санкт-Петербург)

Над обоими режимами — тумблер города (паттерн взят из калькулятора Hit Ceramics, вкладка «Террасный клинкер»). Город определяет, по какой колонке цен считаются **сопутствующие материалы** (клей, грунтовка, гидроизоляция, затирка) — см. справочник 9.3. По умолчанию — Москва. Цена самой плитки/ступеней — из CMS (от города не зависит, редактируется вручную).

### 9.1 Режим A — Лестница / крыльцо (поэлементный расчёт ступеней)

#### 9.1.1 Лестничные марши (динамические строки «+/−»)

Расчёт ведётся по **маршам**. По умолчанию один марш; кнопка **«+ Добавить марш»** добавляет строку, кнопка **«−»** (или 🗑) у строки удаляет её (если маршей > 1). Параметры каждого марша независимы и суммируются.

| Поле строки марша | Тип | Описание |
|---|---|---|
| Название (опц.) | text | «Крыльцо», «Лестница к террасе» |
| Кол-во ступеней, N | number | Число ступеней в марше |
| Ширина марша, W (м) | number | Ширина ступени по фронту |
| Глубина проступи, d (м) | number | Глубина ступени (для базовой плитки и наклона) |
| Высота подступёнка, h (м) | number | Высота вертикали ступени |
| Внешних углов марша | select | 0 / 1 / 2 |
| «−» Удалить марш | button | если маршей > 1 |

Общие переключатели (на весь расчёт):

| Поле | Тип | Описание |
|---|---|---|
| Облицовывать подступёнки? | toggle | Да/Нет |
| Боковины (плинтус)? | toggle | Да/Нет — облицовка наклонной боковины марша |
| Верхняя площадка (крыльцо): Д×Ш (м) | number×number | Опц. — базовая плитка площадки |

#### 9.1.2 Выбор системы, размера плитки и цен

| Поле | Тип | Описание |
|---|---|---|
| Бренд / Коллекция / Цвет | select | Из каталога CMS (Paradyz, Exagres, Маркастрой, Stroeher, Westerwälder Klinker, Interbau) |
| Размер базовой плитки | radio | **30×30** (11.11 шт/м²) / **30×60** (5.56 шт/м²) |
| Длина фронтального элемента, Lф (м) | авто | Из артикула (напр. 1.2) |
| Длина подступёнка, Lп (м) | авто | Из артикула |
| Длина плинтуса, Lпл (м) | авто | Из артикула |
| Ширина угловой ступени, Wугл (м) | авто | Из артикула |
| Цена фронтальной (₽/шт) | number | Редактируемое |
| Цена угловой L/R (₽/шт) | number | Редактируемое |
| Цена подступёнка (₽/шт) | number | Редактируемое |
| Цена базовой плитки (₽/шт) | number | Редактируемое |
| Цена плинтуса (₽/шт) | number | Редактируемое |

> **Правило элементов:** список доступных элементов и их длины берутся строго из массива `elements[]` артикула (раздел 17). Если у артикула нет, например, плинтуса — соответствующая опция скрыта/заблокирована. Калькулятор не предлагает элементы, которых нет у товара.

#### 9.1.3 Формулы (запас на подрез k = 5%, т.е. ×1.05; суммируются по всем маршам)

Для каждого марша *i*:

| Величина | Формула |
|---|---|
| Погонаж проступи (м) | `Pпро_i = N_i × W_i` |
| Угловые элементы (шт) | `Aугл_i = N_i × внешних_углов_i` |
| Фронтальные элементы (шт) | `Fфр_i = ceil( (Pпро_i − Aугл_i × Wугл) / Lф × 1.05 )` |
| Подступёнки (шт), если включены | `Fпод_i = ceil( Pпро_i / Lп × 1.05 )` |
| Длина наклона марша (м) | `Lнакл_i = N_i × √(d_i² + h_i²)` |
| Плинтус (шт), если боковины | `Fпл_i = ceil( (2 × Lнакл_i) / Lпл × 1.05 )` |

Итоги по всем маршам и площадке:

| Величина | Формула |
|---|---|
| Угловых / фронтальных / подступёнков / плинтусов | `Σ по маршам` каждого типа |
| Базовая плитка площадки (шт) | `Fбаз = ceil( (Дпл × Шпл) × шт_м²(размер) × 1.05 )`, где шт_м² = 11.11 (30×30) или 5.56 (30×60) |
| Поддонов | `ceil( кол-во_по_типу / шт_поддон )` суммарно |
| **Стоимость элементов** | `Σ ( кол-во_элемента × цена_элемента )` |
| Сопутствующие материалы | по площади облицовки (площадка + проступи + подступёнки), см. 9.3 |
| Вес поставки (т) | `Σ( кол-во × вес_шт ) / 1000` |

#### 9.1.4 Пример расчёта (Режим A)

Два марша. Марш 1 (крыльцо): N = 5, W = 1.5 м, d = 0.30 м, h = 0.15 м, 2 угла. Марш 2 (короткий): N = 3, W = 1.2 м, d = 0.30, h = 0.15, 2 угла. Подступёнки да, боковины да, площадка 1.5 × 1.2 м, размер базовой 30×30 (11.11 шт/м²). Артикул: Lф = 1.2 м, Lп = 1.2 м, Lпл = 0.3 м, Wугл = 0.32 м.

Марш 1:
- `Pпро = 5 × 1.5 = 7.5 м`; угловых `5 × 2 = 10`
- Фронтальные: `ceil((7.5 − 10×0.32)/1.2 × 1.05) = ceil(3.76) = 4 шт`
- Подступёнки: `ceil(7.5/1.2 × 1.05) = ceil(6.56) = 7 шт`
- Наклон: `5 × √(0.09+0.0225) = 5 × 0.335 = 1.68 м`; плинтус `ceil(2×1.68/0.3 × 1.05) = 12 шт`

Марш 2:
- `Pпро = 3 × 1.2 = 3.6 м`; угловых `3 × 2 = 6`
- Фронтальные: `ceil((3.6 − 6×0.32)/1.2 × 1.05) = ceil((3.6−1.92)/1.2 ×1.05) = ceil(1.47) = 2 шт`
- Подступёнки: `ceil(3.6/1.2 × 1.05) = ceil(3.15) = 4 шт`
- Наклон: `3 × 0.335 = 1.01 м`; плинтус `ceil(2×1.01/0.3 × 1.05) = ceil(7.07) = 8 шт`

Площадка: `ceil(1.5×1.2 × 11.11 × 1.05) = ceil(21.0) = 21 шт`.

**Итого:** угловых 16, фронтальных 6, подступёнков 11, плинтусов 20, базовая 21 шт. Стоимость = сумма по ценам элементов; сопутствующие материалы — по площади облицовки в выбранном городе (9.3); вес = сумма весов / 1000.

### 9.2 Режим B — Терраса / площадка / дорожки (по площади)

#### 9.2.1 Геометрия участков (динамические строки)

| Поле строки участка | Тип | Описание |
|---|---|---|
| Название (опц.) | text | «Терраса», «Дорожка» |
| Длина (м) | number | — |
| Ширина (м) | number | — |
| 🗑 Удалить | button | если строк > 1 |

Кнопка **«+ Вычет»** (бассейн, клумба, колонна): площадь вычитается.

| Поле вычета | Тип | Описание |
|---|---|---|
| Длина (м) / Диаметр (м) | number | прямоугольный или круглый вычет |
| Ширина (м) | number | для прямоугольного |
| 🗑 Удалить | button | — |

#### 9.2.2 Параметры укладки

| Поле | Тип | Описание |
|---|---|---|
| Формат плиты | select | Только форматы артикула из CMS (для опор — рекомендованы ≥ 400×400) |
| Способ укладки | radio | **На клей по стяжке** / **На регулируемые опоры (HILST)** / На гравийно-песчаное основание |
| Раскладка | radio | Прямая (запас 5%) / Со смещением (8%) / Диагональ (10%) / Сложная геометрия (12%) |
| Цена за шт (или за м²) | number | Редактируемое |
| Сопутствующие материалы (клей, грунтовка, гидро, затирка)? | toggle | Если на клей — считаются по городу (9.3) |

#### 9.2.4 Справочник расхода опор HILST LIFT (опор на 1 м² террасы)

Калькулятор выбирает колонку по фактической площади участка (ближайшая снизу из 20 / 50 / 100 / 1000 м²).

| 750 × 750 | 4.55 | 4.22 | 3.94 | 3.68 |

#### 9.2.5 Сопутствующие материалы для клеевой укладки — см. справочник 9.3.

#### 9.2.6 Формулы (Режим B)

| Величина | Формула |
|---|---|
| Площадь нетто (м²) | `Sнетто = Σ(Дi×Шi) − Σ вычеты` |
| Площадь с запасом (м²) | `Sзап = Sнетто × (1 + запас)` |
| Плит (шт) | `ceil( Sзап / Sплиты )`, где `Sплиты` из формата |
| Поддонов | `ceil( плит / шт_поддон )` |
| **Стоимость плитки** | `плит × цена_шт` (или `Sзап × цена_м²`) |
| Опоры (шт), если на опоры | `ceil( Sнетто × опор_м²(формат, площадь) )` по таблице 9.2.4 → стоимость |
| Сопутствующие материалы, если на клей | по таблице 9.3 (расход × Sнетто, по городу) → мешки/канистры → стоимость |
| **Итого материалы** | `стоим_плитки + стоим_опор_или_материалов` |
| Вес поставки (т) | `(плит × вес_плиты + мешки × фасовка) / 1000` |

#### 9.2.7 Пример расчёта (Режим B — на опоры)

Терраса 5 × 4 м (20 м²), формат 600×600 (Sплиты = 0.36 м², вес ~16 кг, шт/поддон из CMS), на регулируемые опоры HILST, прямая раскладка.

- `Sнетто = 20 м²`; `Sзап = 20 × 1.05 = 21 м²`
- Плит: `ceil(21 / 0.36) = ceil(58.3) = 59 шт`
- Опоры: площадь 20 м² → колонка «20 м²», формат 600×600 → **6.80 опор/м²**; `ceil(20 × 6.80) = 136 опор`
- Стоимость = 59 × цена_плиты + 136 × цена_опоры.

#### 9.2.8 Пример расчёта (Режим B — на клей, город Москва)

Терраса 6 × 4 м, вычет круглой клумбы Ø1.0 м, формат 600×1200 (Sплиты = 0.72 м², вес 32 кг, шт/поддон 40), на клей, прямая раскладка, сопутствующие материалы вкл., город **Москва**.

- `Sнетто = 24 − π×0.5² = 24 − 0.79 = 23.21 м²`; `Sзап = 23.21 × 1.05 = 24.37 м²`
- Плит: `ceil(24.37 / 0.72) = ceil(33.8) = 34 шт`; поддонов `ceil(34/40) = 1`
- Клей Flex FKC (5 кг/м², меш. 25 кг): `23.21 × 5 = 116.1 кг → ceil(116.1/25) = 5 мешков × 2261.83 = 11 309 ₽`
- Грунтовка UG (0.4 кг/м², кан. 10 кг): `23.21 × 0.4 = 9.28 кг → ceil(9.28/10) = 1 × 1322.84 = 1 323 ₽`
- Гидроизоляция MDS (4 кг/м², меш. 25 кг): `23.21 × 4 = 92.8 кг → ceil(92.8/25) = 4 × 1741.04 = 6 964 ₽`
- Затирка FUG FBR (0.45 кг/м², меш. 25 кг): `23.21 × 0.45 = 10.4 кг → ceil(10.4/25) = 1 × 1393.25 = 1 393 ₽`
- Сопутствующие материалы итого ≈ **20 989 ₽** (Москва); для СПб — по второй колонке цен (9.3).
- Стоимость = 34 × цена_плиты + 20 989 ₽.

### 9.3 Справочник сопутствующих материалов (цены по городу)

## 19. Критерии приёмки

### Обязательные (без них не принимается)
- [ ] Все блоки главной корректны на 320 / 768 / 1280 px
- [ ] Страницы решений (крыльцо, лестница, терраса, дорожки, опоры, бассейн) созданы с уникальным контентом
- [ ] Подстраницы брендов созданы с уникальным контентом (по факту списка брендов)
- [ ] Карточка товара переключает элемент/формат — цена, размер, вес, нормы меняются динамически
- [ ] **Калькулятор, Режим A (ступени):** добавление/удаление лестничных маршей «+/−» работает, поэлементный расчёт по маршам корректен и совпадает с примером 9.1.4, расчёт в штуках зависит от размера плитки (30×30 / 30×60), цены редактируются, результат мгновенный
- [ ] **Калькулятор, Режим B (терраса):** расчёт по площади корректен, совпадает с примерами 9.2.7 (опоры) и 9.2.8 (клей), расход опор берётся из таблицы HILST 9.2.4 по формату и площади, результат мгновенный
- [ ] **Глобальный переключатель города (Москва/СПб)** меняет цены сопутствующих материалов согласно справочнику 9.3
- [ ] Сопутствующие материалы (клей Flex FKC, грунтовка UG, гидроизоляция MDS, затирка FUG) считаются по расходу и цене города
- [ ] Калькулятор не предлагает элементы/форматы, которых нет у артикула
- [ ] Все формы услуг отправляют заявки в Битрикс24 в нужную воронку с тегом
- [ ] Квиз работает, заявка из квиза → CRM с тегом «Квиз», данные расчёта попадают в поля сделки
- [ ] Карта объектов отображается, маркеры кликабельны
- [ ] Сравнение: до 3 артикулов корректно
- [ ] Коллтрекинг: звонки создают сделки
- [ ] UTM-метки передаются в поля сделки
- [ ] Яндекс.Метрика: цели на формы, телефон, квиз, оба режима калькулятора
- [ ] HTTPS, PageSpeed Mobile ≥ 70, LCP < 2.5 сек
- [ ] CMS: менеджер обновляет цену за 3 действия; CSV-импорт работает
- [ ] Видео-герой: без звука, без управления, с fallback-фото
